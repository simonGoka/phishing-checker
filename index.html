Phishing Email Checker

The problem

Phishing is when someone sends a fake email pretending to be a real company (like a bank) to steal your password or money. It’s one of the most common ways people get hacked, because it tricks the person instead of the computer.

Try it: paste an email

    How to protect yourself

    • Look at the sender address. Real companies use their real domain, not weird spellings.
    • Don’t click links in a panic. Type the website address yourself instead.
    • Use two-factor authentication (2FA). Even if your password is stolen, they can’t log in easily.
    • Use a password manager. It won’t fill in your password on a fake site.
    • Report it. Tell your school or workplace IT so others don’t fall for it.

    How this checker works

    It adds up points for warning signs: urgent words, links that start with http instead of https, shortened links, links to a number address, and a sender name with numbers swapped for letters. It’s a simple tool, so it can be wrong. If you’re unsure, don’t click.
